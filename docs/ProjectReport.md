# Project Report: Smart Receipt Scanner

## 1. Abstract
The Smart Receipt Scanner extracts text from receipt images using OCR and categorizes expenses automatically.

## 2. Introduction
The system helps users analyze spending through simple automation.

## 3. Methodology
1. User uploads receipt.
2. OCR extracts text.
3. Regex finds amount.
4. NLP-rules categorize expense.
5. Results shown to user.

## 4. Results
System successfully extracted text and categorized receipts.

## 5. Conclusion
A lightweight AI-based expense analysis tool built using Python Flask and OCR.
